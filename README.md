# Парсер каталога с выгрузкой в Excel и отслеживанием цен

Собирает весь каталог интернет-магазина (категории → страницы → товары) и выгружает в оформленный Excel и CSV.
При повторном запуске показывает, какие цены изменились, и может прислать отчёт в Telegram.

Демонстрационный источник — [books.toscrape.com](https://books.toscrape.com), учебный сайт для практики парсинга:
**1000 товаров из 50 категорий за ~11 секунд.** Пример результата — в папке `output/`.

## Что в Excel
- **Каталог** — название, категория, цена, рейтинг, наличие, кликабельная ссылка; фильтры и закреплённая шапка
- **Сводка** — по каждой категории: количество, средняя / минимальная / максимальная цена, средний рейтинг
- **Изменения цен** — что подорожало (красным) и подешевело (зелёным) с прошлого запуска, новые и пропавшие товары

## Возможности
- Параллельная загрузка с ограничением (по умолчанию 5 запросов) и паузой — не нагружает сайт
- Повторы с нарастающей паузой при сетевых сбоях
- Снимок цен после каждого запуска → сравнение при следующем
- Отчёт в Telegram: `--notify` + переменные `TG_BOT_TOKEN`, `TG_CHAT_ID`
- CSV в UTF-8 с BOM и разделителем `;` — открывается в русском Excel без «кракозябр»

## Запуск
```bash
uv sync
uv run price-parser --out output                 # весь каталог
uv run price-parser --categories 3               # быстрая проба на 3 категориях
uv run price-parser --notify                     # + отчёт в Telegram
uv run pytest                                    # тесты без сети
```
Для регулярного мониторинга — cron или планировщик Windows, например раз в день.

## Под другой сайт
Логика разбора — в `scrape.py` (`parse_categories`, `parse_listing`): это чистые функции, их меняют под разметку
нужного сайта, остальное (параллельность, Excel, история цен, Telegram) остаётся как есть.
